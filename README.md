# 3D Print Tracker

Docker + PostgreSQL + PHP 3D Print Management MVP.

Features:
- Dashboard
- Filament Inventory
- Druckjobs
- Automatischer Filamentverbrauch
- Maintenance Tracker
- Adminer

Start:

```bash
docker compose up -d --build
```

Web:
- App: http://localhost:8080
- Adminer: http://localhost:8081
